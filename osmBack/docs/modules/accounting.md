# الوحدة المحاسبية (Accounting Module) 💰

تعتبر المحاسبة هي القلب النابض لنظام EyeCare. يدعم النظام المحاسبة المزدوجة (Double-entry bookkeeping) بشكل آلي بالكامل.

## 📋 المميزات الرئيسية
- **دليل الحسابات (Chart of Accounts)**: شجرة حسابات مرنة وقابلة للتخصيص لكل فرع.
- **قيود اليومية الآلية**: يتم إنشاء القيود تلقائياً عند البيع، المشتريات، أو استلام الأدوية.
- **مراكز التكلفة**: تتبع الربحية على مستوى الفرع أو الموظف.
- **التقارير المالية**: ميزان المراجعة، قائمة الدخل، والميزانية العمومية.

## ⚙️ كيف يتم إنشاء القيود؟

عند تنفيذ عملية بيع، يقوم النظام باستدعاء `Accounting Signals` التي تقوم بـ:
1. التعرف على الحسابات المدينة والدائنة (مثلاً: الصندوق مدين والمبيعات دائن).
2. التأكد من توازن القيد.
3. ترحيل القيد فوراً للحسابات.
