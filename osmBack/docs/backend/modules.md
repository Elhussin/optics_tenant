# 📦 شرح تطبيقات الواجهة الخلفية (Backend Apps Breakdown)

تتكون الواجهة الخلفية من مجموعة تطبيقات مديولية (Modular Apps) داخل مجلد `osmBack/apps/`:

---

## 📂 دليل التطبيقات ووظائفها

| اسم التطبيق | الوصف والمسؤولية الرئيسية |
| :--- | :--- |
| **`accounting`** | إدارة شجرة الحسابات (Chart of Accounts)، دفتر اليومية (`GeneralJournal`)، خطوط القيود، الأرباح والخسائر، وتوليد قيد COGS. |
| **`sales`** | إدارة فواتير المبيعات، المدفوعات، عروض الأسعار، وسجلات الإرجاع. |
| **`products`** | إدارة الكتالوج، الماركات، مقاسات العدسات والاطارات، حركات المخزون (`StockMovement`) ومتوسط التكلفة WAC. |
| **`prescriptions`** | كشوفات فحص النظر والعدسات (Sph, Cyl, Axis, Addition, PD) وربطها بالعميل وفاتورة البيع. |
| **`crm`** | بيانات العملاء، تصنيفاتهم، تاريخ المشتريات، وبرامج الولاء. |
| **`hrm`** | سجلات الموظفين، الأدوار، الورديات، والعمولات. |
| **`branches`** | إدارة الفروع، الخزائن، والمخازن التابعة لكل فرع وتحديد الرؤية بحسب فرع المستخدم. |
| **`tenants`** | إدارة نطاقات المستأجرين وبناء الـ Schemas. |
| **`users`** | المصادقة والأذونات والأدوار (Roles & Permissions). |
