# 🩺 تطبيق الوصفات الطبية (Prescriptions Backend App)

مسار الكود: `osmBack/apps/prescriptions/`

---

## 🎯 الغرض والمسؤولية
التطبيق التخصصي الفريد لمركز البصريات لحفظ وإدارة كشوفات وفحوصات النظر ومقاسات العدسات:
1. قياسات العين اليمنى (OD) والعين اليسرى (OS).
2. القياسات البصرية: SPH (Sphere), CYL (Cylinder), AXIS, ADD (Addition), PD (Pupillary Distance).
3. ربط الوصفة برقم العميل وفاتورة البيع ذات الصلة.
