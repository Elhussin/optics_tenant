### ✅ **1. إصلاح جلب الفحوصات للعميل المختار فقط**

**المشكلة:**
- كانت الفحوصات الطبية تُجلب لجميع العملاء
- عند تغيير العميل، تبقى الفحوصات القديمة ظاهرة

**الملف المُعدّل:**
- `/osmFront/src/features/orders/create/steps/PrescriptionStep.tsx`

**التعديلات:**
```typescript
// استخدام useMemo لتحديث query parameters تلقائياً
const queryParams = React.useMemo(() => ({
  customer: store.customerId,
  page_size: 20,
}), [store.customerId]);

// مسح البيانات القديمة عند تغيير العميل
useEffect(() => {
  if (store.customerId) {
    setPrescriptions([]);
    setExpandedId(null);
    setEditingId(null);
    setShowNewPrescription(false);
    store.setPrescription(null);
    query.refetch();
  }
}, [store.customerId]);
```

**الفوائد:**
- ✅ يتم جلب فحوصات العميل المختار فقط
- ✅ مسح تلقائي للفحوصات عند تغيير العميل
- ✅ إلغاء اختيار الفحص السابق تلقائياً
- ✅ تجربة مستخدم أفضل وأكثر وضوحاً

**الملفات المُعدّلة:**
1. `/osmFront/src/features/orders/create/steps/PaymentStep.tsx`

**التعديلات:**

#### في PaymentStep:
```tsx
// قبل: grid من الأزرار

  {PAYMENT_TYPE_OPTIONS.map((option) => (
    <button ...>{option.label}</button>
  ))}

// بعد: Select dropdown
<Select
  value={store.paymentType}
  onValueChange={(value) => store.setPaymentType(value as any)}
>
  <SelectTrigger className="h-12">
    <SelectValue placeholder="اختر طريقة الدفع" />
  </SelectTrigger>
  <SelectContent>
    {PAYMENT_TYPE_OPTIONS.map((option) => (
      <SelectItem key={option.value} value={option.value}>

      </SelectItem>
    ))}
  </SelectContent>

```

#### نقل نوع الطلب:
- ✅ تم **نقل** اختيار نوع الطلب من `CustomerStep` إلى `PaymentStep`

- ✅ وضعه بجانب طريقة الدفع في grid متجاوب

**الفوائد:**
- ✅ **توفير المساحة** - من 3 صفوف أزرار إلى select واحد
- ✅ **سهولة الاستخدام** - اختيار أسرع من dropdown
